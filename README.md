# CogniTutor

CogniTutor is an adaptive, AI-assisted tutoring application designed to assist students by providing Socratic guidance, detecting cognitive load, and mapping prerequisite concept relationships.

## Core Modules
1. **Socratic Tutor**: Guides students through problem-solving using structured, open-ended questioning instead of direct answers.
2. **Confusion & Mode Switcher**: Detects student confusion and dynamically switches to simpler, step-by-step explanatory modes.
3. **Cognitive Load Diagnostics**: Analyzes engagement and difficulty markers during learning modules.
4. **Prerequisite Concept Graph**: Visualizes concept relationships and traces learning gaps back to foundational prerequisites.
