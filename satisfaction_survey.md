# CogniTutor — Post-Session Survey

Give this right after the student downloads their session log (see
`evaluation_plan.md`) and takes the post-test quiz.

## Part A: Rate each statement (1 = Strongly Disagree, 5 = Strongly Agree)

1. The tutor's questions helped me think through the problem myself,
   rather than just giving me the answer.
   `1  2  3  4  5`

2. When I seemed confused, the explanation that followed (analogy,
   breakdown, example, etc.) actually helped.
   `1  2  3  4  5`

3. When the tutor mentioned an earlier concept I might be missing
   (e.g. "you may want to review Functions first"), that connection
   made sense to me.
   `1  2  3  4  5`

4. I felt more engaged using this than reading a textbook/watching a
   video on the same topic.
   `1  2  3  4  5`

5. I would use a tool like this again to study.
   `1  2  3  4  5`

## Part B: Open-ended

6. What was the most helpful moment during your session?

7. What was confusing or frustrating about using the tool itself
   (not the topic — the tool)?

## Facilitator notes

The session log JSON (downloaded from the app sidebar) already
captures message count, session duration, confusion-trigger count,
mode-switch count, and root-cause-trigger count automatically — no
need to hand-count these. Use this space only for things the log can't
capture:

- Anything the student said out loud but didn't type: _______
- Any technical issues observed: _______
- Any moments the student seemed stuck and the tool didn't help: _______
